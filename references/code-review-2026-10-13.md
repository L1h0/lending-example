# Повторная проверка кода — 13 октября 2026 года

Основа проверки: `3b22d2225ce0bf1136f2ac87f5176a6a099ed2e9`, согласованная приватная версия после возврата прежнего оформления «Об эксперте».

## Исправления

- Рекомендация формата теперь читает реально выбранный пункт при запуске и при `pageshow`. Восстановление состояния формы браузером больше не оставляет рекомендацию другого формата.
- Подготовленный запрос получает номер версии. Ответ асинхронного копирования обновляет статус и фокус только для запроса, из которого началось копирование.
- Сброс результата и ошибки поля вынесены в небольшие функции; повторяющийся код обработки формы удалён.

Добавлены четыре проверки: восстановленный выбор при запуске, возврат из истории, поздний успешный и поздний неуспешный ответ буфера обмена после замены запроса. Все четыре воспроизвели ошибки до исправления и проходят после него.

## Проверка

`npm run check` проходит: сборка, JavaScript, HTML/локальные ресурсы, 23 сценария взаимодействий, адаптивные фотографии и эталон оформления. Эталон структуры, текстов, каскада CSS и исходных изображений сохранён без изменения.

Проверка зависимостей `npm audit` не обнаружила известных уязвимостей в текущем lockfile на момент проверки. Инструменты разработки не попадают в браузерную сборку.

Пересмотрены контроллеры формы, рекомендаций, меню, шапки и ленты, сборка статических файлов и проверки GitHub Actions. Подготовлена конфигурация защиты `main`; её административное включение требует отдельного действия владельца, описанного в [main-protection.md](main-protection.md).

В этой среде недоступно браузерное визуальное сравнение. DOM-проверки не измеряют отрисовку, сетевую скорость или Lighthouse; сохранение оформления подтверждается неизменным HTML/CSS и оригинальными ресурсами.
