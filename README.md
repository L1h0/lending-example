## Работа с сайтом

HTML и CSS редактируются в корне репозитория, JavaScript — в корне и `modules/`, фотографии и логотипы — в `public/`.
`docs/` — готовая копия для GitHub Pages. Она создаётся командой сборки и хранится в Git вместе с исходниками.
Для сборки и проверок нужны Node.js 24.15+ и Python 3. Перед первым запуском выполните `npm ci`; инструменты разработки не загружаются браузером.

```bash
npm ci         # установить инструменты сборки и проверок
npm run dev    # собрать и открыть локальный сервер (по умолчанию порт 4173)
npm run build  # обновить docs/ после редактирования
npm run check  # сборка, синтаксис, HTML, ресурсы и имеющиеся проверки интерактивности
```

После правок снова выполните сборку и перезагрузите страницу. Исходники и `docs/` коммитьте вместе.
Не редактируйте `docs/` вручную. Отправка запроса готовит текст и черновик письма локально; автоматической отправки нет.
