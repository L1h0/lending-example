# Лендинг Елены Чипсановой

Статический одностраничный сайт на чистых HTML, CSS и JavaScript.

## Файлы

- `index.html` — вся структура и содержание страницы.
- `styles.css` — дизайн и адаптивная вёрстка.
- `script.js` — FAQ и анимация появления секций.
- `public/` — фотографии и favicon.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```
