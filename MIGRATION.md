## Просмотр любого этапа

```bash
git fetch origin
git switch --detach origin/checkpoint/2026-10-11-08-final-style
npm run check
npm run dev
```

Для исходного сайта используйте `origin/backup/before-redesign-2026-10-11`.
Для редактирования создайте новую ветку от выбранного снимка, например:

```bash
git switch -c rollback/chosen-version origin/checkpoint/2026-10-11-07-sections-02-04
```

## Возврат файлов с сохранением истории

Сначала сохраните незакоммиченные изменения. В рабочей ветке восстановите выбранный снимок и создайте новый коммит:

```bash
git restore --source=origin/backup/before-redesign-2026-10-11 --staged --worktree -- .
git commit -m "Вернуть исходную версию лендинга"
```

Для возврата к промежуточной версии замените источник на нужную контрольную ветку.
Так история последующих изменений остаётся доступной, без `reset --hard` и принудительной отправки.

## Публикация

Владелец подтвердил изменение `main` и публичного сайта 11 октября 2026 года.
Pull request: https://github.com/L1h0/lending-example/pull/1. Слияние сохраняет отдельные коммиты всех восьми этапов и дополнительный коммит подготовки к публикации.

Существующая задача GitHub Pages `pages build and deployment` берёт `docs/` из `main`.
Сборка `npm run build` обновляет этот каталог; `npm run check` проверяет готовые страницы, ресурсы и интерактивность.
Основная страница и политика конфиденциальности разрешают индексацию и содержат канонические адреса публичного сайта.
Приватный макет Sites сохраняет исходные снимки для проверки и восстановления этапов.

Публичный сайт: https://l1h0.github.io/lending-example/
Откат файлов в `main` новым коммитом также обновит публичный сайт через GitHub Pages.
